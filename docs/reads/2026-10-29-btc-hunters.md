## One tooling lesson, logged on the row

The hunter scripts write by date. Running them with --write on a day the 15:25 routine already wrote replaces the routine's receipt instead of adding to it. This run did that to the options candidates file for 10/29 (routine receipt ebcb2d94, which ranked file 2026-10-29.ranked.json still cites). The short receipt was restored from git; the options candidates file for the routine's universe run is gone and would need a re-run to recreate with a new id. Interactive hunter runs on a routine day go to a suffixed file until the scripts refuse to overwrite.
